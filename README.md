# Porto rc.25 per Windows x64

Versione di prova per copiare foto e video dal telefono al PC tramite cavo USB. Scarica Porto-0.1.0-rc.25-win-x64.zip, scegli **Estrai tutto** in Windows e apri **Porto.exe** nella cartella estratta.

Questa versione riduce le scritture dei registri sul PC. La durata di un trasferimento su iPhone dipende anche dal dispositivo, dal collegamento e dalla dimensione dell’album.

Confronta l’impronta dello ZIP con il file SHA256SUMS.txt. Il tag identifica questa distribuzione di prova. Il commit della compilazione è 335cf12843657f06333471b6af4f3b7ead108a8b.
